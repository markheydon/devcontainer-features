# Copilot Likes

Opinionated devcontainer feature with tools that GitHub Copilot often assumes are available.

## Includes

- ripgrep (rg)
- fd
- fzf
- jq
- bat
- eza (modern ls)
- git-delta
- direnv

## Usage

```json
"features": {
  "ghcr.io/markheydon/devcontainer-features/copilot-likes:1": {}
}
```
